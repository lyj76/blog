# PyTorch 训练循环与优化器：zero_grad / backward / step

训练循环是 LLM 训练脚本的核心骨架。这篇把循环结构、优化器机制、梯度裁剪、学习率调度一次讲清。

## 1. 完整训练循环模板

```python title="train-loop.py"
import torch
from torch.optim import AdamW

optimizer = AdamW(model.parameters(), lr=3e-4)

for epoch in range(1, num_epochs + 1):              # 外层：轮
    model.train()
    for step, batch in enumerate(dataloader):      # 中层：批
        input_ids = batch["input_ids"].to(device)
        labels = batch["labels"].to(device)

        outputs = model(input_ids=input_ids, labels=labels)
        loss = outputs.loss

        optimizer.zero_grad()
        loss.backward()
        torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
        optimizer.step()

        if step % 10 == 0:
            print(f"Epoch {epoch}/{num_epochs} | Step {step}/{len(dataloader)} | Loss: {loss.item():.4f}")
```

- **三层结构**：epoch（轮）→ step（批）→ batch（样本，DataLoader 内部处理）
- 每个 step 都走 `zero_grad → backward → step` 三步
- `model.train()` 切训练模式（影响 Dropout / BatchNorm），评估时换 `model.eval()`

## 2. 三步顺序为什么不能乱

```python title="three-steps.py"
optimizer.zero_grad()   # 1. 清空 .grad
loss.backward()         # 2. 反向传播，填充 .grad
optimizer.step()        # 3. 用 .grad 更新参数
```

| 步骤 | 内部动作 | 错位的后果 |
| --- | --- | --- |
| `zero_grad()` | 把所有参数 `.grad` 清零（或置 `None`） | 不清 → 梯度累加历史值，更新方向错 |
| `backward()` | 沿计算图反向，把梯度**累加**到 `.grad` | 在 `step` 后 → 用的是旧梯度 |
| `step()` | 按 `.grad` 与优化器状态更新 `param.data` | 在 `zero_grad` 前 → 把刚算的梯度清掉 |

::::important
**顺序铁律**：`zero_grad → backward → step`。`step` 之后才能进入下一个 batch，因为 `step` 用的是 `backward` 刚填的 `.grad`。
::::

## 3. SGD vs AdamW：怎么选

| 优化器 | 更新规则（一句话） |
| --- | --- |
| `SGD` | `param -= lr * grad`（纯梯度下降，可选动量） |
| `AdamW` | `param -= lr * 自适应步长` + 解耦的权重衰减（LLM 微调首选） |

::::note
**为什么 LLM 用 AdamW 不用 SGD**：Adam 系列对每个参数自适应调学习率（按梯度历史二阶矩缩放），对稀疏梯度、不同尺度参数更稳；AdamW 的解耦权重衰减比 Adam 的 L2 正则更符合原始权重衰减语义。
::::

（`params` / `param_groups` / `state` 等内部数据结构的完整讲解见「优化器内部」篇。）

## 4. 只优化部分参数

```python title="filter-params.py"
trainable_params = [p for p in model.parameters() if p.requires_grad]
optimizer = AdamW(trainable_params, lr=3e-4)
```

- 列表推导式过滤出 `requires_grad=True` 的参数
- 冻结的参数根本不进优化器，`step()` 不会动它们
- LoRA 场景的标准写法：原模型冻结，只把 A/B 交给优化器

（`trainable_params` 的底层数据结构、以及"冻结参数为什么不进优化器"，见「优化器内部」篇。）

## 5. loss.item() 记录损失

```python title="loss-item.py"
loss = model(input_ids=input_ids, labels=labels).loss
loss_value = loss.item()   # Python float，脱离计算图

print(f"Step {step} | Loss: {loss_value:.4f}")
```

- `.item()` 把标量张量转成 Python `float`，**脱离计算图**
- 不调用 `.item()` 直接打印会输出 `tensor(0.54, grad_fn=...)`，既难读又留张量在图里
- 训练日志、TensorBoard、W&B 记录都用 `.item()` 取标量

## 6. 梯度裁剪

```python title="grad-clip.py"
torch.nn.utils.clip_grad_norm_(model.parameters(), max_norm=1.0)
```

- 在 `backward` 之后、`step` 之前调用
- 计算所有参数梯度的**全局范数**，若超过 `max_norm` 就按比例缩放
- 防止梯度爆炸（梯度太大 → 参数更新太大 → 训练发散）

::::warning
**位置不能错**：`clip_grad_norm_` 必须在 `backward` 之后（梯度已算出）、`step` 之前（更新前裁剪）。放在 `zero_grad` 后 `backward` 前没意义，放在 `step` 后已经晚了。
::::

## 7. 学习率调度器

```python title="lr-scheduler.py"
from torch.optim.lr_scheduler import StepLR

optimizer = AdamW(model.parameters(), lr=1e-3)
scheduler = StepLR(optimizer, step_size=5, gamma=0.5)   # 每 5 轮 lr *= 0.5

for epoch in range(num_epochs):
    for step, batch in enumerate(dataloader):
        # ... 训练 step ...
        pass
    scheduler.step()   # 每个 epoch 末调一次
```

- `scheduler` 持有 `optimizer` 引用，`scheduler.step()` 时按规则调低 `optimizer.lr`
- **它改的其实是 `optimizer.param_groups[0]['lr']`**——scheduler 只动 param_groups 里的学习率字段（分组结构见「优化器内部」篇 §3）
- `StepLR`：每 `step_size` 个 epoch 把 lr 乘 `gamma`
- 调用时机：`scheduler.step()` 在 epoch 末（不是每个 step），与 `optimizer.step()` 区分

## 8. f-string 打日志

```python title="f-string-log.py"
print(f"Epoch {epoch}/{num_epochs} | Step {step}/{len(dataloader)} | Loss: {loss.item():.4f} | LR: {optimizer.param_groups[0]['lr']:.2e}")
```

- `f"..."` 内嵌 `{变量}`，直接拼字符串
- `:.4f` 保留 4 位小数；`:,` 千分位；`:.2e` 科学计数
- `optimizer.param_groups[0]['lr']` 取当前学习率（调度器改的就是这里）

## 小结

| 语法 | 作用 / 返回 |
| --- | --- |
| `optimizer.zero_grad()` | 清空所有参数 `.grad` |
| `loss.backward()` | 反向传播，填充 `.grad` |
| `optimizer.step()` | 用 `.grad` 更新参数 |
| `clip_grad_norm_(params, max_norm)` | 梯度范数裁剪（防爆炸） |
| `scheduler.step()` | 调整学习率（epoch 末） |
| `loss.item()` | 标量张量 → Python float |
| `[p for p in model.parameters() if p.requires_grad]` | 过滤可训练参数 |
