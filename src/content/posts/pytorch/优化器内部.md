# PyTorch 优化器内部：params / param_groups / state

`optimizer = AdamW(trainable_params, lr=3e-4)` 这一行背后是三个数据结构：params 列表、param_groups、state。理解它们，优化器就不再是"魔法"。

## 1. 优化器能输入什么：params 与超参数

`AdamW(第一参数, 超参数...)`——第一参数可以是**任意可迭代的 Tensor / Parameter 集合**，其余全是超参数：

```python title="optimizer-input.py"
from torch.optim import AdamW

# 写法一：全部参数（model.parameters() 是生成器）
optimizer = AdamW(model.parameters(), lr=3e-4)

# 写法二：过滤后的参数列表
trainable = [p for p in model.parameters() if p.requires_grad]
optimizer = AdamW(trainable, lr=3e-4)

# 写法三：param_groups（按组管理，每组可覆盖超参数）
optimizer = AdamW([
    {"params": backbone.parameters(), "lr": 1e-5},   # 骨干：小学习率
    {"params": [lora_a, lora_b],        "lr": 1e-3},   # LoRA：大学习率
], lr=3e-4)   # 未覆盖的组用这个默认 lr
```

| 输入 | 类型 | 说明 |
| --- | --- | --- |
| 第一参数 `params` | 可迭代的 Tensor/Parameter | 要优化的参数（生成器、列表、字典列表都行） |
| `lr` | float | 学习率（必给，无默认值） |
| `betas` | `tuple[float, float]` | Adam 家族：一阶 / 二阶矩指数衰减系数 |
| `eps` | float | 防止除零的小常数 |
| `weight_decay` | float | 权重衰减（AdamW 为解耦形式） |

所有超参数会被存进 `optimizer.defaults` 字典——它是每组参数的"默认配置"。

## 2. trainable_params 的数据结构：Parameter 列表

```python title="trainable-params.py"
trainable = [p for p in model.parameters() if p.requires_grad]
type(trainable)      # list
type(trainable[0])   # torch.nn.parameter.Parameter（Tensor 子类）
```

- **类型**：`list[nn.Parameter]`。`nn.Parameter` 是 `Tensor` 的子类，只是默认 `requires_grad=True` 并注册进 Module
- **过滤原理**：`if p.requires_grad` 筛掉冻结参数，剩下的才是要训练的参数
- **关键：优化器持有的是引用，不是拷贝**。`step()` 原地修改 `param.data`，训练才真正改到模型里的参数——如果传的是拷贝，训练就不会生效
- **为什么只传参数就够了**：前向用参数算出 loss → `backward()` 把梯度填进每个参数的 `.grad` → 优化器**读 `.grad`、改 `.data`**，闭环完成

（参数的注册与结构见「nn.Module 与参数管理」篇；梯度的产生见「自动求导与梯度」篇。）

## 3. param_groups：按组管理参数

`param_groups` 是优化器内部最核心的数据结构——**一个 `list[dict]`**：

```python title="param-groups.py"
optimizer = AdamW(model.parameters(), lr=3e-4, weight_decay=0.01)
print(optimizer.param_groups)
# [{'params': [<Parameter ...>, ...], 'lr': 0.0003, 'betas': (0.9, 0.999),
#   'eps': 1e-08, 'weight_decay': 0.01, 'amsgrad': False, ...}]
```

- 每个 dict = 一组参数 + 这组的超参数；**不指定的项继承 `defaults`**
- `optimizer.param_groups[0]['lr']`：当前学习率——**学习率调度器改的就是这里**（见「训练循环与优化器」篇）
- 多组场景：骨干和 LoRA 用不同 lr、冻结与解冻切换
- `add_param_group()`：训练中途加一组（如解冻某个模块后把它加入训练）：

```python title="add-param-group.py"
optimizer.add_param_group({"params": [head.weight], "lr": 1e-4})
```

## 4. state：优化器状态字典

`state` 保存每个参数在优化算法里**累积的历史状态**（不是参数本身）：

```python title="state-example.py"
# 走完一次 backward + step 后：
print(type(optimizer.state))          # collections.defaultdict
print(optimizer.state)                # key = 参数对象
# {<Parameter weight>: {'step': tensor(1.), 'exp_avg': tensor([...]), 'exp_avg_sq': tensor([...])}, ...}
```

| 状态 | 含义（Adam 家族） |
| --- | --- |
| `step` | 该参数被更新了多少次（用于偏差修正） |
| `exp_avg` | 一阶矩 m（梯度均值，动量） |
| `exp_avg_sq` | 二阶矩 v（梯度平方均值，自适应步长分母） |

- **为什么必须存状态**：Adam 的下一步更新依赖历史梯度统计，丢了状态 Adam 就等于从头开始
- **续训 / 迁移的载体**：`optimizer.state_dict()` 序列化 `{'state': ..., 'param_groups': [...]}`，`load_state_dict()` 恢复——保存模型时把优化器状态一起存，断点续训才能保持动量

## 5. 核心方法与属性

| 方法 | 作用 |
| --- | --- |
| `step()` | 遍历 `param_groups` 的每个参数：读 `.grad` + `state` → 按更新规则改 `param.data` |
| `zero_grad()` | 清空所有参数的 `.grad`（`set_to_none=True`，省显存） |
| `state_dict()` / `load_state_dict()` | 保存 / 恢复优化器状态（续训用） |
| `add_param_group()` | 动态增加一组参数 |

| 属性 | 结构 | 说明 |
| --- | --- | --- |
| `param_groups` | `list[dict]` | 参数与每组的超参数（scheduler 改 lr 的地方） |
| `defaults` | `dict` | 默认超参数 |
| `state` | `defaultdict` | 每参数的优化历史状态 |

::::note
**`step()` 是"读梯度、改数据"，不是"算梯度"**：梯度由 `loss.backward()` 产生并填进 `.grad`，优化器只消费它。所以顺序必须是 `zero_grad → backward → step`（见「训练循环与优化器」篇）。
::::

## 6. 只优化部分参数：LoRA 场景

过滤可训练参数是构造 `trainable_params` 的核心套路：

```python title="filter-params.py"
trainable_params = [p for p in model.parameters() if p.requires_grad]
optimizer = AdamW(trainable_params, lr=3e-4)
```

- 冻结的参数（`requires_grad=False`）**根本不进优化器**——`step()` 不会碰它们，`backward()` 也不会给它们存梯度
- 列表推导式把"全部参数"过滤成"可训练参数"，这一步产出的就是第 2 节的 `trainable_params`
- LoRA 标准写法：原模型整体 `requires_grad=False`，只把 A / B 矩阵交给优化器

（冻结参数的做法见「冻结参数与参数量统计」篇。）

## 小结

| 语法 | 作用 / 数据结构 |
| --- | --- |
| `AdamW(params, lr=...)` | 第一参数是参数集合，其余是超参数（存进 `defaults`） |
| `trainable_params` | `list[nn.Parameter]`，优化器持有引用（读 `.grad` 改 `.data`） |
| `optimizer.param_groups` | `list[dict]`，参数分组 + 组级超参数 |
| `optimizer.state` | `defaultdict`，每参数的 Adam 状态（m / v / step） |
| `optimizer.step()` | 读 `.grad` + `state` → 更新 `param.data` |
| `optimizer.zero_grad()` | 清空 `.grad`（set_to_none） |
| `optimizer.state_dict()` | 保存状态（续训 / 迁移） |
