# PyTorch 张量广播与组合：broadcasting / cat / stack / 索引

形状不同的张量怎么运算、怎么拼、怎么筛？这篇把广播、拼接、掩码索引、argmax/where 这些「张量组合与筛选」的核心操作一次讲清。

> 归属：**PyTorch · `torch`** —— 张量操作属于训练引擎 PyTorch。

## 1. 广播（broadcasting）

两个张量做逐元素运算时，形状不必完全相同，PyTorch 会按规则自动扩展：

```python title="broadcast-example.py"
import torch

a = torch.randn(4, 3)      # [4, 3]
b = torch.randn(3)         # [3]
c = a + b                  # [4, 3] —— b 被广播成 [4, 3]

d = torch.randn(4, 1)      # [4, 1]
e = torch.randn(1, 3)      # [1, 3]
f = d + e                  # [4, 3] —— 两边都广播
```

**过程（从右往左对齐，缺的维补 1，1 可以扩展成任意值）**：

```
例 1：a=[4,3] 与 b=[3] 相加
    a : [ 4 , 3 ]
    b : [     3 ]     ← 右对齐；左边缺的维度视作 1
        ↓ 补齐
    b : [ 1 , 3 ]     ← 1 可以扩展成 4
        ↓ 逐元素运算
  结果: [ 4 , 3 ]     ← 每维取较大者

例 2：d=[4,1] 与 e=[1,3] 相加
    d : [ 4 , 1 ]     ← 1 扩展成 3
    e : [ 1 , 3 ]     ← 1 扩展成 4
        ↓
  结果: [ 4 , 3 ]     ← 两边都扩展
```

**规则三条**：从**最右侧**逐维比较；某维相等**或其一为 1** 则可广播；都不为 1 且不相等 → 报错：

```python title="broadcast-error.py"
g = torch.randn(4, 3)
h = torch.randn(4)         # [4]，对齐后是 [1, 4]
g + h                      # RuntimeError: The size of tensor a (3) must match
                           # the size of tensor b (4) at non-singleton dimension 1
```

::::warning
**最易踩的坑**：`b = torch.randn(3)` 是一维的，对齐到 `[4, 3]` 时被当成 `[1, 3]` 再广播；而 `torch.randn(4)` 对齐后是 `[1, 4]`，与 `[4, 3]` 在第 1 维（3 vs 4）冲突。想让 `[4]` 当成列向量广播，先 `b.unsqueeze(1)` 变 `[4, 1]`。
::::

## 2. torch.cat：沿已有维度拼接

`torch.cat` 把多个张量**沿已存在的维度**拼起来，结果维度数不变——想象把两张表**粘**在一起：

```python title="cat-example.py"
x = torch.randn(2, 3)
y = torch.randn(2, 3)

z0 = torch.cat([x, y], dim=0)   # [4, 3] —— 沿第 0 维拼（行变多）
z1 = torch.cat([x, y], dim=1)   # [2, 6] —— 沿第 1 维拼（列变多）
```

```
x = ┌ 1  2  3 ┐        y = ┌ 4  5  6 ┐
    └ 1  2  3 ┘            └ 4  5  6 ┘

cat(dim=0)：沿"行"方向叠 → [4, 3]
    ┌ 1  2  3 ┐
    ┌ 1  2  3 ┐   ← x 的两行
    ┌ 4  5  6 ┐   ← y 的两行
    └ 4  5  6 ┘

cat(dim=1)：沿"列"方向接 → [2, 6]
    ┌ 1  2  3 │ 4  5  6 ┐
    └ 1  2  3 │ 4  5  6 ┘
     ← x 的列 →│← y 的列 →
```

- `dim` 指定沿哪一维拼，**只有该维可以不同**，其他维必须完全一致
- 结果的 `ndim` 与输入相同（不新增维度）
- 拼接列表顺序决定结果顺序：`cat([x, y])` 中 `x` 在前

## 3. torch.stack：新增一维堆叠

`torch.stack` 把多个**形状完全相同**的张量堆起来，**新增一个维度**——想象把向量**叠成卡片**：

```python title="stack-example.py"
x = torch.randn(3,)            # [3]
y = torch.randn(3,)            # [3]

s0 = torch.stack([x, y], dim=0)   # [2, 3] —— 新增第 0 维
s1 = torch.stack([x, y], dim=1)   # [3, 2] —— 新增第 1 维
```

```
x = [ 1  2  3 ]     y = [ 4  5  6 ]     都是 [3]

stack(dim=0)：新增第 0 维，像叠卡片 → [2, 3]
    ┌ 1  2  3 ┐   ← x 放进第 0 张
    └ 4  5  6 ┘   ← y 放进第 1 张

stack(dim=1)：新增第 1 维 → [3, 2]
    ┌ 1  4 ┐
    │ 2  5 │     ← 每个位置的元素配成一对
    └ 3  6 ┘
```

- 输入张量形状必须**完全相同**（不像 cat 只要求非拼接维相同）
- `dim` 指定新维度插在哪儿，结果 `ndim = 输入 ndim + 1`
- 等价于先 `unsqueeze` 再 `cat`：`stack([x,y], 0)` ≈ `cat([x[None], y[None]], 0)`

| 操作 | 输入要求 | 输出 ndim | 典型场景 |
| --- | --- | --- | --- |
| `torch.cat` | 非拼接维相同 | 不变 | 拼序列、拼 batch |
| `torch.stack` | 完全相同 | +1 | 把多个样本堆成 batch |

## 4. split 与 chunk：把张量切块

```python title="split-chunk-example.py"
x = torch.randn(6, 4)

# split：按每块大小切
parts = torch.split(x, 2, dim=0)         # 3 个 [2, 4]
# split 也可按"每块大小列表"切
parts2 = torch.split(x, [1, 3, 2], dim=0)  # [1,4] / [3,4] / [2,4]

# chunk：按"块数"切（尽量均分）
chunks = torch.chunk(x, 3, dim=0)        # 3 个 [2, 4]
```

- `split(tensor, split_size, dim)`：按**每块大小**切，返回 tuple；`split_size` 是 int 或 list
- `chunk(tensor, chunks, dim)`：按**目标块数**切，返回 tuple；不能均分时最后一块较小
- 两者都返回 tuple，可用 `a, b, c = torch.split(...)` 解包

## 5. 布尔掩码索引

用比较运算得到布尔张量，再用它筛选元素：

```python title="mask-example.py"
x = torch.randn(5)
mask = x > 0            # tensor([True, False, True, True, False])
pos = x[mask]           # 一维张量，只含正数元素（形状不定）

# 配合 where 做条件赋值
y = torch.where(x > 0, x, torch.zeros_like(x))   # 负数位置填 0
```

- `mask` 必须与 `x` **形状相同**（或可广播），返回一维张量
- 索引结果**不保留原形状**，是按选中元素顺序排的一维张量
- 常用于过滤 padding、统计有效 token 数：`(labels != -100).sum()`

## 6. argmax：取最大值的索引

```python title="argmax-example.py"
logits = torch.tensor([[0.1, 0.9, 0.0],
                       [0.7, 0.2, 0.1]])
next_token = torch.argmax(logits, dim=-1)   # tensor([1, 0])
```

- `argmax(dim)` 返回沿 `dim` 方向最大值的**索引**（整数张量）
- 不指定 `dim` 时返回整个张量里最大值的扁平索引
- 生成下一个 token 的标准套路：`logits` 形状 `[batch, seq, vocab]`，`dim=-1` 取词表维 → `[batch, seq]`，取最后一个位置就是下一个 token id

::::tip
**`dim=-1` 的含义**：负数索引从右数，`-1` 是最后一维。LLM 输出 `[batch, seq, vocab]`，最后一维是词表，`argmax(dim=-1)` 直接得到每个位置的预测 token id。
::::

## 7. torch.where：条件选择

```python title="where-example.py"
x = torch.randn(3)
y = torch.ones(3)
z = torch.where(x > 0, x, y)   # 正数取 x，否则取 y
```

- `torch.where(condition, x, y)`：按 `condition` 的 True/False，从 `x` / `y` 对应位置取值
- 三个张量形状需相同或可广播
- 等价于 `condition.float() * x + (~condition).float() * y`，但更高效、更直观

## 小结

| 语法 | 作用 / 返回 |
| --- | --- |
| `a + b`（形状不同） | 广播后逐元素运算，结果形状取每维较大者 |
| `torch.cat([x, y], dim)` | 沿已有维拼接，ndim 不变 |
| `torch.stack([x, y], dim)` | 新增一维堆叠，ndim +1 |
| `torch.split(x, size, dim)` | 按每块大小切，返回 tuple |
| `torch.chunk(x, n, dim)` | 按块数切，返回 tuple |
| `x[mask]` | 布尔掩码筛选，返回一维张量 |
| `torch.argmax(x, dim)` | 沿 dim 取最大值索引 |
| `torch.where(cond, x, y)` | 条件选择 |
