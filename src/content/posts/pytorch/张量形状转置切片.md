# PyTorch 张量形状、转置与切片

深度学习代码里到处是形状操作。这篇把 LoRA 代码里出现的全部整理出来，看懂形状就不怕读代码了。

## 1. 形状：`shape` 与 `shape[i]`

```python title="shape-example.py"
inputs.input_ids.shape     # torch.Size([batch, seq_len])，如 [4, 256]
inputs.input_ids.shape[1]  # 256 —— 第 2 个维度（seq_len）
inputs.input_ids.shape[0]  # 4 —— 第 1 个维度（batch）
```

- `tensor.shape` 返回 `torch.Size`（本质是 tuple），`shape[0]` 取第 1 维、`shape[1]` 第 2 维
- 模型输入张量约定：**第 0 维永远是 batch**，第 1 维是序列长度

## 2. 转置：`.T`

```python title="transpose-example.py"
LoRA_A.shape    # [r, in_features]，如 [8, 4096]
LoRA_A.T        # [in_features, r]，如 [4096, 8] —— 转置，交换前两维
```

- `.T` 是转置快捷写法，等价 `tensor.transpose(0, 1)`
- 矩阵乘法要求「前一个的列 = 后一个的行」，转置就是用来对齐维度的

## 3. 矩阵乘法：`@`

```python title="matmul-example.py"
out2 = x @ self.LoRA_A.T @ self.LoRA_B.T
```

逐步推导形状（假设 `x` 形状 `[batch, seq, in]`）：

| 步骤 | 运算 | 形状 |
| --- | --- | --- |
| 1 | `x @ LoRA_A.T` | `[b, s, 4096] @ [4096, 8]` → `[b, s, 8]` |
| 2 | `(… ) @ LoRA_B.T` | `[b, s, 8] @ [8, out]` → `[b, s, out]` |

`@` 要求：**A 的最后一维 = B 的倒数第二维**，结果 = `[A前维..., B后维]`。

## 4. 切片：`tensor[a:b]`

```python title="slice-example.py"
outputs[0]              # 取 batch 里第 0 条：[seq, vocab]
outputs[0][prompt_len:] # 从第 prompt_len 个 token 切到末尾
```

- `tensor[i]` 取第 i 个元素（降一维）
- `tensor[start:]` 从 start 切到末尾；`tensor[:end]` 从头到 end（不含）
- 生成后剥离 prompt 就是这个套路：`outputs[0][prompt_len:]` = 「整段输出去掉 prompt 部分」

::::note
**Python 切片记忆**：`a:b` 含 `a` 不含 `b`。`[:]` 全部、`[1:]` 从 1 到末尾、`[:-1]` 去掉最后一个（负索引从右数）。
::::

## 5. 形状调整：`view` / `reshape` / `permute` / `unsqueeze`

四个都是"改形状"，区别在**改法**：

```python title="reshape-example.py"
x = torch.randn(2, 3, 4)

x.view(6, 4)          # 展平前两维 → [6, 4]（要求连续内存，见下）
x.reshape(6, 4)       # 同 view，但内存不连续时自动复制，更安全
x.permute(2, 0, 1)    # 按给定顺序重排维度 → [4, 2, 3]（不改变数据顺序的"换轴"）
x.unsqueeze(0)        # 在位置 0 加一个长度为 1 的维 → [1, 2, 3, 4]
x.squeeze(1)          # 去掉长度为 1 的维 → [2, 4]（squeeze() 不带参数去掉所有 1 维）
```

| 方法 | 做什么 | 数据顺序 | 是否复制 |
| --- | --- | --- | --- |
| `view(新形状)` | 把现有数据**重新解释**成新形状 | 不变 | 否（要求连续内存，否则报错） |
| `reshape(新形状)` | 同 view，但不连续时**自动复制**后再重排 | 不变 | 视情况 |
| `permute(轴顺序)` | **交换轴**（转置的通用版） | 不变 | 否（结果可能不连续） |
| `unsqueeze(n)` | 加一个大小为 1 的维（广播对齐用） | 不变 | 否 |
| `squeeze(n)` | 去掉大小为 1 的维 | 不变 | 否 |

::::warning
**`view` 的连续内存要求**：`view` 要求张量内存连续（`contiguous`）。`permute` / `transpose` 之后内存不再连续，再对结果 `view` 会报错——需要先 `.contiguous()`。不确定时直接用 `reshape` 最省心。
::::

**换轴的典型场景**：注意力计算里把 `[batch, seq, head, dim]` 的 head 维挪到前面做矩阵乘，`permute(0, 2, 1, 3)` 一步到位。

## 6. 堆叠与拼接：`stack` / `cat`

两个"把多个张量合成一个"的操作，区别在**新增维度还是沿已有维度**：

```python title="stack-vs-cat.py"
x = torch.tensor([1, 2, 3])        # 形状 [3]
y = torch.tensor([4, 5, 6])        # 形状 [3]

torch.stack([x, y])                # tensor([[1,2,3],[4,5,6]])  形状 [2,3]  ← 新增第 0 维
torch.stack([x, y], dim=1)         # tensor([[1,4],[2,5],[3,6]]) 形状 [3,2]  ← 新增第 1 维
torch.cat([x, y], dim=0)           # tensor([1,2,3,4,5,6])       形状 [6]   ← 沿已有维拼接
```

| 操作 | 输入要求 | 输出 | 本质 |
| --- | --- | --- | --- |
| `torch.stack` | 形状**完全相同** | `ndim + 1` | **新增一个维**，把 N 个张量放进这个维 |
| `torch.cat` | 非拼接维相同 | `ndim` 不变 | 沿已有维**拼长** |

**`stack` 的本质**：在最前面（或指定位置）插一个新维度，然后把这 N 个张量依次放进这个维度——等价于先 `unsqueeze` 再 `cat`：

```python title="stack-equivalent.py"
torch.stack([x, y])               # 等价于：
torch.cat([x.unsqueeze(0), y.unsqueeze(0)], dim=0)
# x.unsqueeze(0) = [[1,2,3]]，y.unsqueeze(0) = [[4,5,6]]
# cat 沿第 0 维 → [[1,2,3],[4,5,6]]
```

**为什么 DataLoader 的 batch 第 0 维永远是 batch 大小**：`default_collate` 就是把 N 个样本 `torch.stack` 到一起——stack 在最前面插入的新维，正好就是 batch 维。

::::note
**结构递归视角（通用知识）**：stack 是"叶子操作"——它是处理任意嵌套结构（元组/字典/张量）时**最内层**的那个动作。外层按容器类型分组递归，到叶子张量就 `torch.stack`。这就是 DataLoader 能统一处理元组和字典的原因（详见「Dataset 与 DataLoader」篇）。
::::

## 小结

| 语法 | 作用 |
| --- | --- |
| `tensor.shape[1]` | 取第 2 维（模型输入通常是 seq_len） |
| `tensor.T` | 转置（交换前两维） |
| `A @ B` | 矩阵乘（A 末维 = B 倒数第二维） |
| `tensor[0][prompt_len:]` | 取样本 + 切片剥离 prompt |
| `view(形状)` / `reshape(形状)` | 重排形状（view 要求连续内存） |
| `permute(轴序)` / `unsqueeze` / `squeeze` | 换轴 / 加维 / 去维 |
| `torch.stack([x, y], dim)` | 新增一维堆叠（N 个张量进新维） |
| `torch.cat([x, y], dim)` | 沿已有维拼接 |
