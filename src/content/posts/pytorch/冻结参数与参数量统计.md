# PyTorch 冻结参数与参数量统计

LoRA 的精髓是「只训练少量适配器参数」——实现手段就是 `requires_grad` 冻结 + 参数量统计。

## 1. `requires_grad`：参数的"开关"

每个参数张量都有 `requires_grad` 属性（`bool`）：

```python title="requires-grad-example.py"
param.requires_grad = True    # 参与梯度计算（可训练）
param.requires_grad = False   # 冻结：不计算梯度、不被优化器更新
```

**冻结后的参数**：`backward()` 时不为其计算梯度，`optimizer.step()` 也不更新它——权重保持不变。

## 2. 冻结整个模块：遍历 `parameters()`

```python title="freeze-module.py"
for para in self.original_linear.parameters():
    para.requires_grad = False   # 冻结原层所有参数（权重 + 偏置）
```

- `module.parameters()` 迭代该模块的所有参数（含子模块）
- 逐一把 `requires_grad` 置 `False` 即完成冻结

**LoRA 场景**：冻结整个原模型，只留 A/B 可训练：

```python title="freeze-lora.py"
for name, param in model.named_parameters():
    if "lora" not in name.lower():    # 名字里不含 lora 的（即原模型参数）
        param.requires_grad = False
```

## 3. 过滤可训练参数：列表推导式

```python title="filter-trainable.py"
trainable_params = [p for p in model.parameters() if p.requires_grad]
optimizer = AdamW(trainable_params, lr=3e-4)   # 只优化可训练部分
```

优化器**只接收可训练参数**，冻结的参数根本不会出现在 optimizer 里。

::::tip
**`requires_grad` 与优化器的关系**：即使把冻结参数传给 `AdamW`，它们也不会更新（梯度为 `None`）。但显式过滤更清晰、更省内存——推荐 `[p for p in model.parameters() if p.requires_grad]`。
::::

## 4. 统计参数量：`numel()`

```python title="numel-example.py"
param.numel()   # 返回元素总数（int）
```

- `numel()` = **num**ber of **el**ements，把张量所有维度乘起来
- 例：`torch.empty(4096, 4096).numel()` → `16,777,216`

## 5. 完整统计模板（可训练占比）

LoRA 里打印「只训了百分之几的参数」是标准操作：

```python title="trainable-stats.py"
trainable_params = 0
all_param = 0
for _, param in model.named_parameters():
    num_params = param.numel()
    all_param += num_params
    if param.requires_grad:
        trainable_params += num_params

percentage = 100 * trainable_params / all_param
print(f"总参数量:     {all_param:,}")          # :, 千分位分隔
print(f"可训练参数量: {trainable_params:,}")
print(f"可训练占比:   {percentage:.4f}%")      # 如 0.1354%
```

- `{all_param:,}`：f-string 加 `,` 自动千分位（1,000,000）
- `named_parameters()` 拿到名字 + 参数，逐个累加

::::note
**LoRA 的效果**：一个 0.5B 模型（约 5 亿参数），LoRA 只训练 A/B 矩阵，可训练占比通常 **不到 1%**——这就是 LoRA「省显存、快训练、效果接近全量微调」的由来。
::::

## 小结

| 语法 | 作用 |
| --- | --- |
| `param.requires_grad = False` | 冻结单个参数 |
| `for p in module.parameters(): p.requires_grad = False` | 冻结整个模块 |
| `[p for p in model.parameters() if p.requires_grad]` | 过滤可训练参数 |
| `param.numel()` | 参数元素总数 |
| `f"{num:,}"` | 千分位格式化 |
