# LoRA 相关论文与方法演进

每一篇后续论文都改动了 LoRA 的某一块拼图。读它们之前先固定四个问题：**动了哪一层、解决了什么问题、没解决什么、引用时结论该归给谁**。下面按这个框架过一遍。

## <<LoRA原论文>>

> 论文：Hu et al., [LoRA: Low-Rank Adaptation of Large Language Models](https://arxiv.org/abs/2106.09685)。

针对全量微调"参数、梯度、优化器状态全要钱"的成本，LoRA 冻结 $W_0$，在目标线性变换旁路加入

$$
\Delta W=\frac{\alpha}{r}BA.
$$

只优化 $A,B$，推理前把 $\Delta W$ 合并回 $W_0$（完整链路见 [[论文阅读/lora/01-lora主线]]）。

**贡献边界**：低秩适配参数化、初始化、合并、目标层与参数效率实验属于 LoRA 原论文；而"SVD 存在最佳低秩近似"是标准线性代数（见 [[论文阅读/lora/02-svd与最佳低秩近似]]），别记到 LoRA 头上。

## <<QLoRA量化微调>>

> 论文：Dettmers et al., [QLoRA: Efficient Finetuning of Quantized LLMs](https://arxiv.org/abs/2305.14314)。

LoRA 省的是可训练参数，基础模型权重一分没动——175B 的模型对单卡仍然太大。QLoRA 把基础模型以 4-bit 量化保存，适配器照常训练：

| 层次 | QLoRA 的处理 |
| --- | --- |
| 基础模型权重 | 4-bit 量化存储/计算路径 |
| 适配器 | 仍然训练 LoRA 参数 |
| 显存工程 | NF4、double quantization、paged optimizers |

一句话定位：QLoRA 的核心扩展是**量化基础模型 + LoRA + 显存工程**。NF4、double quantization、paged optimizer 这些成果归属 QLoRA，不在 LoRA 原论文的账上。

## <<AdaLoRA自适应秩>>

> 论文：Zhang et al., [AdaLoRA: Adaptive Budget Allocation for Parameter-Efficient Fine-Tuning](https://arxiv.org/abs/2303.10512)。

普通 LoRA 给每个目标层同一个 $r$，但不同层对任务的重要程度差得很远，均匀分配是浪费。AdaLoRA 在总参数预算约束下随训练动态调整各层 rank，把容量让给更重要的层和方向：

| 普通 LoRA | AdaLoRA |
| --- | --- |
| 每层 rank 通常固定 | rank 随训练动态分配 |
| 参数预算由人工预设 | 预算仍有上限，但分配自适应 |
| 低秩参数化不变 | 重点改变 rank 的预算管理 |

它的低秩参数化还是 LoRA 那一套，贡献点是**预算管理**——别把它说成"换了一种 rank 算法"。

## <<DoRA权重分解>>

> 论文：Liu et al., [DoRA: Weight-Decomposed Low-Rank Adaptation](https://arxiv.org/abs/2402.09353)。

LoRA 把对权重的调整全塞进一个低秩增量里，方向和幅值的变化绑在一起，优化路径可能偏离全量微调。DoRA 把权重显式拆开：

$$
W=m\frac{V}{\lVert V\rVert_c},
$$

$m$ 管幅值、$V$ 管方向，方向部分再用低秩适配。它改的是**权重参数化方式**，不是 $A,B$ 的摆放顺序——"把 $A/B$ 换一下顺序"算不上 DoRA 的贡献。

## <<LoRA+非对称学习率>>

> 论文：Hayou et al., [LoRA+: Efficient Low Rank Adaptation of Large Models](https://arxiv.org/abs/2402.12354)。

由于 $B_0=0$ 初始化导致初始步 $A$ 缺少梯度流，LoRA+ 证明对称学习率在特征学习范式下存在收敛瓶颈，提出对 $B$ 赋予远大于 $A$ 的学习率：

$$
\eta_B = \lambda_{\eta} \eta_A \quad (\lambda_{\eta} \gg 1).
$$

它的贡献点在于**训练动力学与优化器超参调度**，没有改变模型结构本身（详见 [[论文阅读/lora/04-动力学与目标模块演进]]）。

## <<论文贡献的对照>>

| 结论/机制 | 应归属 |
| --- | --- |
| 冻结 $W_0$、训练 $A/B$、$\Delta W=BA$ | LoRA 原论文 |
| NF4、double quantization、paged optimizer | QLoRA |
| 动态 rank 与预算分配 | AdaLoRA |
| magnitude-direction 分解 | DoRA |
| 非对称学习率 $\eta_B \gg \eta_A$ | LoRA+ |
| rank-r 最佳逼近、奇异值尾部误差 | 标准线性代数，见 [[论文阅读/lora/02-svd与最佳低秩近似]] |

## <<阅读与引用规则>>

写论文或技术笔记时按四层标注：

1. **原论文明确提出的机制**：引用原论文并给出公式/章节。
2. **后续论文的改进**：引用对应后续论文，不写成 LoRA 原始贡献。
3. **标准数学事实**：例如 rank 不等式、SVD 最佳逼近，引用线性代数来源或单独的数学专题。
4. **本文解释性推导**：例如参数量、显存估算、PyTorch 转置映射，明确这是为了理解实现而做的推导。

这条规则防的是过度归因："LoRA 论文里用了低秩"被扩写成"LoRA 论文证明了所有微调更新严格低秩"——第 3 类结论永远不该记到第 1 类头上。
