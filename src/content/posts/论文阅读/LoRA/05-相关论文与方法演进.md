# LoRA 相关论文与方法演进

本篇回答四个问题：**每篇论文改了 LoRA 的哪一层、解决了什么问题、没有解决什么问题、引用时应该把结论归给谁**。

## <<LoRA原论文>>

> 论文：Hu et al., [LoRA: Low-Rank Adaptation of Large Language Models](https://arxiv.org/abs/2106.09685)。

**问题**：全量微调的参数、梯度和优化器状态成本高；但任务适配的更新可能集中在低维方向。

**方法**：冻结 $W_0$，在目标线性变换旁路加入

$$
\Delta W=\frac{\alpha}{r}BA.
$$

训练时只优化 $A,B$，推理前可将 $\Delta W$ 合并回 $W_0$。

**论文贡献边界**：低秩适配参数化、初始化、合并、目标层实验与参数效率实验属于 LoRA 原论文；SVD 的最佳低秩近似定理是标准线性代数，不是 LoRA 论文证明的。

**阅读主线**：[[论文阅读/lora/01-lora主线]] · [[论文阅读/lora/02-svd与最佳低秩近似]]

## <<QLoRA量化微调>>

> 论文：Dettmers et al., [QLoRA: Efficient Finetuning of Quantized LLMs](https://arxiv.org/abs/2305.14314)。

**它解决的问题**：LoRA 减少可训练参数，但基础模型权重仍可能太大。QLoRA 把基础模型以量化形式保存，同时保持低秩适配器可训练。

| 层次 | QLoRA 的处理 |
| --- | --- |
| 基础模型权重 | 4-bit 量化存储/计算路径 |
| 适配器 | 仍然训练 LoRA 参数 |
| 显存工程 | NF4、double quantization、paged optimizers 等 |

**不要混淆**：QLoRA 不是“换一种 rank 的 LoRA”；它的核心扩展是**量化基础模型 + LoRA + 显存优化**。NF4、double quantization、paged optimizer 不应归给 LoRA 原论文。

## <<AdaLoRA自适应秩>>

> 论文：Zhang et al., [AdaLoRA: Adaptive Budget Allocation for Parameter-Efficient Fine-Tuning](https://arxiv.org/abs/2303.10512)。

**它解决的问题**：普通 LoRA 常给每个目标层固定相同的 rank，但不同层对任务的重要性并不相同。

**核心变化**：在总参数预算约束下，训练过程中动态调整各层的 rank，把更多容量分配给更重要的层/方向。

**与普通 LoRA 的边界**：

| 普通 LoRA | AdaLoRA |
| --- | --- |
| 每层 rank 通常固定 | rank 随训练动态分配 |
| 参数预算由人工预设 | 参数预算仍有上限，但分配自适应 |
| 低秩参数化不变 | 重点改变 rank 的预算管理 |

## <<DoRA权重分解>>

> 论文：Liu et al., [DoRA: Weight-Decomposed Low-Rank Adaptation](https://arxiv.org/abs/2402.09353)。

**它解决的问题**：LoRA 的低秩更新对权重方向的调整与权重幅值的变化被绑在一起，优化路径可能与全量微调不同。

**核心变化**：将权重分解为 magnitude 与 direction，对 direction 使用低秩适配：

$$
W=m\frac{V}{\lVert V\rVert_c},
$$

其中 $m$ 表示幅值，$V$ 表示方向参数。DoRA 改变的是权重参数化方式，把 LoRA 的 $A/B$ 顺序换一下算不上它的贡献。

## <<论文贡献的对照>>

| 结论/机制 | 应归属 |
| --- | --- |
| 冻结 $W_0$、训练 $A/B$、$\Delta W=BA$ | LoRA 原论文 |
| NF4、double quantization、paged optimizer | QLoRA |
| 动态 rank 与预算分配 | AdaLoRA |
| magnitude-direction 分解 | DoRA |
| rank-r 最佳逼近、奇异值尾部误差 | 标准线性代数，见 [[论文阅读/lora/02-svd与最佳低秩近似]] |

## <<阅读与引用规则>>

写论文或技术笔记时按四层标注：

1. **原论文明确提出的机制**：引用原论文并给出公式/章节。
2. **后续论文的改进**：引用对应后续论文，不写成 LoRA 原始贡献。
3. **标准数学事实**：例如 rank 不等式、SVD 最佳逼近，引用线性代数来源或单独的数学专题。
4. **本文解释性推导**：例如参数量、显存估算、PyTorch 转置映射，明确这是为了理解实现而做的推导。

这样可以避免“LoRA 论文里用了低秩”被扩写成“LoRA 论文证明了所有微调更新严格低秩”这类过度归因。
