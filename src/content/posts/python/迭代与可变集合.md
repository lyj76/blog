# Python 迭代与可变集合：list() 快照 / enumerate / zip

for 循环遍历集合时最容易踩的坑就是「边遍历边改」。这篇讲清楚 for 的本质、为什么需要 `list()` 快照，以及 enumerate / zip 这两个高频工具。

> 归属：**Python 标准库** —— 语言本身。

## 1. for 的本质：迭代器协议

```python title="for-essence.py"
for x in [1, 2, 3]:
    print(x)

# 等价于：
it = iter([1, 2, 3])       # 拿迭代器
while True:
    try:
        x = next(it)       # 一次取一个
    except StopIteration:
        break
```

- `for x in obj` 会先调 `iter(obj)` 拿迭代器，再反复 `next()` 直到 `StopIteration`
- 列表、字典、生成器都能 `for`，因为它们都实现了 `__iter__`
- 迭代器是「**一次性**」的：取完就空，不能倒带

## 2. 边遍历边修改：`list()` 快照

```python title="list-snapshot.py"
# 错误：遍历的同时修改集合，会跳过元素或报错
for name, module in model.named_modules():
    if isinstance(module, nn.Linear):
        setattr(model, name, new_layer)    # 改了结构 → 遍历行为不可预测

# 正确：先 list() 转成快照，遍历副本，改原对象
for name, module in list(model.named_modules()):
    setattr(model, name, new_layer)
```

- `named_modules()` 返回的是**迭代器**，不是列表
- 在循环里 `setattr` 修改了模型结构，迭代器看到的「下一个」会错乱
- `list(...)` 把迭代器一次性转成列表快照，循环时随便改原对象

::::warning
**为什么必须 `list()`**：迭代器是「惰性」的，每次 `next` 才算下一个元素。遍历过程中改了底层结构，迭代器算出的下一个就不可靠。`list()` 强制一次性算完，固化成快照。

**C++ 类比**：这就是 C++ 的「迭代器失效」。往 `vector` 里 `push_back` 触发扩容后，旧迭代器全失效。Python 没有扩容，但「结构变化导致迭代器看到的状态不一致」是一回事。
::::

## 3. `enumerate`：拿序号 + 元素

```python title="enumerate-example.py"
for i, x in enumerate([10, 20, 30]):
    print(i, x)              # 0 10 / 1 20 / 2 30

for i, x in enumerate(data, start=1):
    print(f"第 {i} 条: {x}")  # 从 1 开始编号
```

- `enumerate(seq)` 同时给「序号 + 元素」，不用自己 `range(len(seq))`
- `start` 参数控制起始编号，默认 0
- 比手动 `i = 0; for x in seq: ...; i += 1` 简洁得多

## 4. `zip`：并行遍历多个序列

```python title="zip-example.py"
names = ["q_proj", "v_proj", "k_proj"]
weights = [w1, w2, w3]

for name, w in zip(names, weights):
    print(name, w.shape)
```

- `zip(a, b)` 把两个序列「拉链」在一起，每次给一对
- 长度不一致时以**短的为准**（Python 3.10+ 可加 `strict=True` 强制等长报错）
- 比用下标 `for i in range(len(names)): names[i], weights[i]` 干净

## 5. 字典的 `items` / `keys` / `values`

```python title="dict-iterate.py"
cfg = {"hidden_size": 768, "num_layers": 12}

for k in cfg:                # 默认遍历 keys
    print(k)
for k, v in cfg.items():     # 同时拿 key 和 value
    print(k, v)
```

- `for k in dict` 默认遍历**键**
- `dict.items()` 给 `(key, value)` 对，`dict.keys()` 给键，`dict.values()` 给值
- 三者返回的都是**视图对象**（不是列表），字典变了视图也变

## 6. 迭代器一次性消费

```python title="iterator-once.py"
def gen():
    yield 1; yield 2; yield 3

it = gen()
print(list(it))             # [1, 2, 3] —— 取完
print(list(it))             # [] —— 已经空了，不会重来

# break 截断：只取前几个
for x in gen():
    if x == 2:
        break                # 提前退出，剩下的没取
```

- 生成器、`map`、`filter`、文件对象都是迭代器，**取完即空**
- 想多次遍历：先 `list(it)` 固化成列表
- 想只取前 N 个：用 `break` 提前退出循环，或 `itertools.islice(it, N)`
- 流式处理大数据集时用生成器逐条产出，省内存但只能遍历一次

## 小结

| 语法 | 作用 |
| --- | --- |
| `for x in obj` | 迭代器协议，`iter` + `next` |
| `list(迭代器)` | 固化快照，遍历时安全修改 |
| `enumerate(seq)` | 拿序号 + 元素 |
| `zip(a, b)` | 并行遍历，以短的为准 |
| `dict.items()` | 同时遍历 key 和 value |
| 迭代器 | 一次性消费，取完即空 |
