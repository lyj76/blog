# Python 字符串处理：in / split / rsplit

处理模型参数名（如 `"model.layers.0.self_attn.q_proj"`）时，字符串方法是最常用的工具。这篇总结三个最常用的。

> 归属：**Python 标准库** —— 语言本身。

## 1. 判断子串：`in`

```python title="in-example.py"
if "q_proj" in name:
    print("这个参数属于注意力查询投影层")
```

`a in name` 判断字符串 `a` 是不是 `name` 的**子串**，返回 `bool`。常用于按名字筛选模块/参数。

::::note
**相关写法**：`name.startswith("model.")` / `name.endswith(".weight")` 判断开头/结尾，`not in` 判断不包含。
::::

## 2. 分割成列表：`split()`

```python title="split-example.py"
name = "model.layers.0.self_attn.q_proj"
parts = name.split(".")        # ['model', 'layers', '0', 'self_attn', 'q_proj']
parts[0]                        # 'model' —— 左边第一个
parts[-1]                       # 'q_proj' —— 右边第一个（Python 负索引从右数）
```

`split(".")` 用 `.` 把字符串切开，返回一个 **list**。两个索引习惯：

- `list[0]` = 左边第一个
- `list[-1]` = 右边第一个（Python 特色：负索引从右往左数）

```python title="split-last-example.py"
layer_name = name.split(".")[-1]   # 取最右边的名字，判断是哪个层
if layer_name in target_modules:   # target_modules = ["q_proj", "v_proj", ...]
    ...
```

## 3. 从右分割一次：`rsplit(".", 1)`

```python title="rsplit-example.py"
name = "encoder.layers.0.self_attn.q_proj"
parent_name, child_name = name.rsplit(".", 1)
# parent_name = "encoder.layers.0.self_attn"
# child_name  = "q_proj"
```

`rsplit(".", 1)` = 从**右边**第一个 `.` 处切开，**只切一次**，返回恰好两部分。这是处理「模块属性路径 → 父模块 + 子模块」的经典写法：

::::tip
**`split` 和 `rsplit` 的区别**：`split(".", 1)` 从左边切第一个点；`rsplit(".", 1)` 从右边切第一个点。取路径的「父 + 子」时用 `rsplit(".", 1)` 最合适——因为子模块名总是在最后。
::::

实战（LoRA 注入时替换子模块）：

```python title="replace-lora-example.py"
if "." in name:
    parent_name, child_name = name.rsplit(".", 1)
    parent_module = model.get_submodule(parent_name)   # 拿到父模块
else:
    parent_module = model
    child_name = name

setattr(parent_module, child_name, lora_layer)         # 用 LoRA 层替换原层
```

## 4. 补充：去首尾空白 `.strip()`

```python title="strip-example.py"
result_text = "  你好，世界  \n"
result_text.strip()   # '你好，世界' —— 去掉首尾空白和换行
```

`decode` 出来的文本常带多余空白，`strip()` 处理后再使用。

## 小结

| 方法 | 作用 | 返回值 |
| --- | --- | --- |
| `a in name` | 判断子串 | `bool` |
| `name.split(".")` | 全部切分 | `list` |
| `name.rsplit(".", 1)` | 从右切一次 | 恰好两个元素 |
| `name.strip()` | 去首尾空白 | `str` |
