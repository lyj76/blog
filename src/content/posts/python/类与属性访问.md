# Python 类与属性访问：__call__ / getattr / setattr

Python 对象能「当函数调用」「当字典用」，全靠几个特殊方法。看懂 `tokenizer(...)` 和 `tokenizer["input_ids"]` 背后的机制，就能理解为什么同一个对象有多种用法。

> 归属：**Python 标准库** —— 语言本身。

## 1. 类的骨架：`class` / `__init__` / `self`

```python title="class-basic.py"
class Linear:
    def __init__(self, in_features, out_features):   # 构造函数
        self.weight = None                            # self 就是 this

layer = Linear(768, 768)                             # 调用 __init__
layer.weight                                         # 访问实例属性
```

- `class` 定义类，`__init__` 是构造函数
- `self` 是实例自身，相当于 C++ 的 `this`，但必须显式写在参数列表第一个
- `self.xxx = ...` 给实例绑属性，`obj.xxx` 读取

## 2. `__call__`：让对象可调用

```python title="call-example.py"
class Tokenizer:
    def __call__(self, text):
        return {"input_ids": [1, 2, 3]}

tok = Tokenizer()
tok("hello")                # 等价于 tok.__call__("hello")
```

- 定义了 `__call__` 的类，实例可以**像函数一样用 `obj(...)` 调用**
- `tokenizer(prompt)` 的根源就是 tokenizer 实现了 `__call__`
- 普通函数本质也是「定义了 `__call__` 的对象」

::::note
**C++ 类比**：`__call__` 就是重载 `operator()`。C++ 里 `struct F { int operator()(int x); };` 让 `F{}(3)` 可调用，Python 用 `__call__` 做同样的事。
::::

## 3. `__getitem__`：让对象支持 `obj[key]`

```python title="getitem-example.py"
class Batch:
    def __getitem__(self, key):
        return self._data[key]

batch = Batch()
batch["input_ids"]          # 等价于 batch.__getitem__("input_ids")
```

- 定义了 `__getitem__` 的类，实例可以**用 `obj[key]` 取值**
- tokenizer 返回的对象能 `out["input_ids"]`、`out["attention_mask"]`，根源就在此
- 字典、列表能 `[key]` 取值，也是因为它们内置实现了 `__getitem__`

::::note
**C++ 类比**：`__getitem__` 就是重载 `operator[]`。`obj[key]` 在两边都是语法糖。
::::

## 4. `getattr`：安全读取属性

```python title="getattr-example.py"
cfg = model.config

cfg.tie_word_embeddings                    # 不存在 → AttributeError 崩溃
getattr(cfg, "tie_word_embeddings", False) # 不存在 → 返回 False，不报错
```

- `getattr(obj, name, default)` 读 `obj` 的 `name` 属性
- **属性存在**：返回属性值，和 `obj.name` 一样
- **属性不存在**：返回 `default`，不抛异常；而 `obj.name` 会直接 `AttributeError`
- 第三个参数可省略，省略时属性不存在会抛异常

::::tip
**为什么用 getattr 带默认值**：不同模型的 config 字段不一定齐全。`getattr(cfg, "tie_word_embeddings", False)` 一行搞定「有就用、没有就用默认」，省去 `if hasattr(...)`。
::::

## 5. `setattr`：用变量名动态设属性

```python title="setattr-example.py"
child_name = "q_proj"                      # 名字是变量
setattr(model, child_name, new_layer)      # 等价于 model.q_proj = new_layer

# 对比：点号写法名字必须写死
model.q_proj = new_layer                   # 不能用变量
```

- `setattr(obj, name, value)` 把 `obj` 的 `name` 属性设为 `value`
- **优势**：`name` 可以是变量（运行时决定），而 `obj.name = v` 的名字必须写死在代码里
- 配套 `hasattr(obj, name)` 判断属性是否存在，返回 `bool`

## 6. `isinstance`：判断类型（含子类）

```python title="isinstance-example.py"
isinstance(module, nn.Linear)               # True / False
isinstance(param, torch.Tensor)            # nn.Parameter 也返回 True
```

- `isinstance(A, B)` 判断 `A` 是否是 `B` 类型，返回 `bool`
- **子类也算**：`nn.Parameter` 继承自 `Tensor`，所以 `isinstance(param, torch.Tensor)` 为 `True`
- 比 `type(A) is B` 更常用，因为后者不认子类

## 小结

| 语法 | 作用 | C++ 对应 |
| --- | --- | --- |
| `__init__` / `self` | 构造函数 / 实例引用 | 构造函数 / `this` |
| `__call__` | 对象可 `obj()` 调用 | `operator()` |
| `__getitem__` | 对象可 `obj[key]` 取值 | `operator[]` |
| `getattr(obj, name, default)` | 安全读属性，缺省不报错 | 无直接对应 |
| `setattr(obj, name, value)` | 用变量名动态设属性 | 无直接对应 |
| `hasattr(obj, name)` | 判断属性是否存在 | 无直接对应 |
| `isinstance(A, B)` | 判断类型（含子类） | `dynamic_cast` |
