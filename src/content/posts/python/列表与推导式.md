# Python 列表与推导式：切片 / 拼接 / 乘法 / 推导

手写数据处理时，列表操作占大头。这篇集中讲切片、拼接、乘法、推导式这几个高频用法，以及嵌套列表的浅拷贝陷阱。

> 归属：**Python 标准库** —— 语言本身。

## 1. 切片：`a[b:c]` 含头不含尾

```python title="slice-example.py"
a = [0, 1, 2, 3, 4, 5]

a[1:4]      # [1, 2, 3] —— 下标 1 到 3，不含 4
a[:3]       # [0, 1, 2] —— 从头到下标 2
a[3:]       # [3, 4, 5] —— 从下标 3 到末尾
a[-1]       # 5 —— 负索引从右数
a[::-1]     # [5, 4, 3, 2, 1, 0] —— 反转
a[::2]      # [0, 2, 4] —— 步长 2
```

- `a[start:stop]` 取下标 `[start, stop)`，**含头不含尾**
- 省略 `start` 从头开始，省略 `stop` 到末尾
- 负索引从右往左数，`-1` 是最后一个
- 第三个参数是步长，`[::-1]` 是反转列表的惯用写法

::::tip
**剥离 prompt 的常见切片**：`outputs[0][prompt_len:]` 跳过前 `prompt_len` 个，只取新生成的 token。`[prompt_len:]` 就是「从 prompt_len 到末尾」。
::::

## 2. 拼接：`a + b` vs `extend`

```python title="concat-example.py"
a = [1, 2]
b = [3, 4]

c = a + b          # [1, 2, 3, 4] —— 新列表，a 和 b 不变
a.extend(b)        # a 变成 [1, 2, 3, 4]，无返回值
a.append(5)        # a 追加单个元素 [1, 2, 3, 4, 5]
```

- `a + b` 生成**新列表**，原列表不变
- `a.extend(b)` 就地扩展，把 `b` 的元素逐个加到 `a` 末尾
- `a.append(x)` 只加一个元素，即使 `x` 是列表也只占一格

## 3. 列表乘法：`[-100] * n` 构造掩码

```python title="list-multiply.py"
mask = [-100] * 5          # [-100, -100, -100, -100, -100]
labels = prompt_mask + real_ids
```

- `[x] * n` 生成 `n` 个 `x` 的列表
- 这是构造训练掩码的根源：prompt 部分填 `-100`（不计入损失），答案部分填真 id
- 比 `[-100, -100, -100, ...]` 手写简洁，且 `n` 可以是变量

## 4. 列表推导式：`[x for x in y if cond]`

```python title="comprehension.py"
nums = [1, 2, 3, 4, 5]

squares = [x * x for x in nums]              # [1, 4, 9, 16, 25]
evens = [x for x in nums if x % 2 == 0]      # [2, 4]
pairs = [(i, x) for i, x in enumerate(nums)] # [(0,1), (1,2), ...]
```

- `[表达式 for 变量 in 序列]` 把循环和构造合并成一行
- 加 `if 条件` 过滤元素，只保留满足条件的
- 表达式可以是任意值，包括元组、函数调用、嵌套推导

::::note
**和 for 循环的关系**：推导式等价于「先建空列表，循环里 append」。`[x*x for x in nums]` ≈ `r=[]; for x in nums: r.append(x*x)`。但推导式更快、更可读。
::::

## 5. 聚合：`sum` / `len` / `min` / `max`

```python title="aggregate.py"
nums = [3, 1, 4, 1, 5]

sum(nums)         # 14 —— 求和
len(nums)         # 5 —— 长度
min(nums)         # 1 —— 最小值
max(nums)         # 5 —— 最大值

# 配合推导式统计模型参数量
total = sum(p.numel() for p in model.parameters())
```

- 四个内置函数对任何可迭代对象都管用
- `sum(生成器)` 不用先转列表，省内存；统计参数量、算平均 loss 都靠这几个

## 6. 嵌套列表的浅拷贝陷阱

```python title="nested-trap.py"
# 错误：三个子列表是同一个对象
grid = [[]] * 3
grid[0].append(1)
print(grid)        # [[1], [1], [1]] —— 全变了

# 正确：用推导式生成独立子列表
grid = [[] for _ in range(3)]
grid[0].append(1)
print(grid)        # [[1], [], [] —— 只有第一个变
```

- `[[]] * n` 生成 `n` 个**同一个空列表的引用**，改一个全跟着变
- `[[] for _ in range(n)]` 每次新建独立列表，互不影响

::::warning
**为什么 `[[]] * n` 会这样**：`*` 复制的是「引用」不是「对象」。`[x] * n` 当 `x` 不可变（如数字）时没问题；当 `x` 可变（如列表、字典）时，所有位置指向同一个对象，改一处全变。要独立子列表，用推导式。

**C++ 类比**：像 `vector<shared_ptr<List>>` 每个元素指向同一个 List，改一个全变。要独立对象得各自 `make_shared`，Python 里就是用推导式各自 `[]`。
::::

## 小结

| 语法 | 作用 |
| --- | --- |
| `a[b:c]` | 切片，含头不含尾 |
| `a[::-1]` | 反转列表 |
| `a + b` | 拼接，生成新列表 |
| `a.extend(b)` | 就地扩展 |
| `[x] * n` | 重复 n 次 |
| `[f(x) for x in y if cond]` | 推导式，循环 + 过滤 |
| `sum / len / min / max` | 聚合统计 |
| `[[] for _ in range(n)]` | 生成独立子列表 |
