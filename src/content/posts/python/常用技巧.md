# Python 常用技巧：迭代复制 / isinstance / setattr / getattr

这些是「遍历模型结构、动态修改属性」时的高频技巧，在 LoRA 注入与权重合并代码中反复出现。

## 1. 边遍历边修改：先复制一份

```python title="iterate-copy.py"
# 错误：遍历的同时修改集合本身，会跳过元素或报错
for name, module in model.named_modules():
    if isinstance(module, nn.Linear):
        setattr(...)   # 修改了结构 → 遍历行为不可预测

# 正确：先 list() 转成快照，遍历的是副本，改的是原对象
for name, module in list(model.named_modules()):
    ...
```

::::warning
**为什么必须 `list()`**：`named_modules()` 返回迭代器，而我们在循环里 `setattr` 修改了模型结构（新增/替换子模块）。遍历一个**正在变化的集合**会导致漏掉元素甚至崩溃。`list(...)` 把迭代器一次性转成列表快照，循环时结构随便改。
::::

## 2. 类型确认：`isinstance(A, B)`

```python title="isinstance-example.py"
isinstance(module, nn.Linear)     # True / False
isinstance(param, torch.Tensor)   # 判断是否是张量
```

`isinstance(A, B)` 判断 `A` 是否是 `B` 类型（或其子类），返回 `bool`。**注意子类也算**——`nn.Parameter` 是 `Tensor` 的子类，所以 `isinstance(param, torch.Tensor)` 为 `True`。

```python title="lora-filter-example.py"
# LoRA 合并时，只处理被替换成 LoRALinear 的层
if isinstance(module, LoRALinear):
    ...
```

## 3. 按路径设置属性：`setattr(A, B, C)`

```python title="setattr-example.py"
setattr(parent_module, child_name, new_linear)
# 等价于: parent_module.child_name = new_linear
```

`setattr(A, B, C)` = 把 `A` 的名为 `B` 的属性设为 `C`。**优势**：`B` 可以是变量（动态的），而 `A.B = C` 的写法名字必须是写死的。

```python title="setattr-dynamic-example.py"
child_name = "q_proj"                       # 名字是变量
setattr(model, child_name, new_layer)       # 等价于 model.q_proj = new_layer

# 写死写法做不到动态：model.child_name = ... 会真的创建名为 child_name 的属性
```

## 4. 安全读取属性：`getattr(A, B, 默认值)`

```python title="getattr-example.py"
getattr(model.config, "tie_word_embeddings", False)
```

`getattr(A, B)` 获取 `A` 的 `B` 属性；**第三个参数给默认值**——属性不存在时返回默认值而不是抛 `AttributeError`：

```python title="getattr-vs-dot.py"
# 属性存在时等价：
model.config.tie_word_embeddings

# 属性不存在时：
model.config.tie_word_embeddings      # ❌ AttributeError: 直接崩溃
getattr(model.config, "tie_word_embeddings", False)   # ✅ 返回 False，安全
```

::::tip
**为什么用 getattr 带默认值**：不同模型的 `config` 字段不一定齐全（有的模型没有 `tie_word_embeddings`）。用 `getattr(..., False)` 一行代码就做了「有就用，没有就用默认值」，省去 `if hasattr(...)` 判断。
::::

## 5. 补充：f-string 字符串格式化

训练代码里打印日志几乎都用 f-string：

```python title="fstring-example.py"
epoch, step, loss = 2, 20, 1.2345678
print(f"Epoch [{epoch}/3] | Step [{step}] | Loss: {loss:.4f}")
# 输出: Epoch [2/3] | Step [20] | Loss: 1.2346

total = sum(p.numel() for p in model.parameters())
print(f"参数量: {total / 1e6:.2f}M")     # 1e6 = 100 万，: .2f = 保留 2 位小数
```

- `f"..."` 前缀 + `{变量}` 直接嵌入变量
- `{loss:.4f}` 表示格式化为 4 位小数；`{x:.2f}` 2 位小数
- 本质是把任意表达式放进 `{}`：`{total / 1e6:.2f}` 先算除法再格式化

## 小结

| 技巧 | 用途 |
| --- | --- |
| `list(迭代器)` | 遍历时安全修改集合 |
| `isinstance(A, B)` | 判断类型（含子类） |
| `setattr(A, B, C)` | 用变量名动态设置属性 |
| `getattr(A, B, 默认)` | 安全读取属性，缺省不报错 |
| `f"{x:.2f}"` | 字符串嵌入变量并格式化 |
