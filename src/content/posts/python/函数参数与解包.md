# Python 函数参数与解包：*args / **kwargs

Python 函数收参数的方式比 C++ 灵活：既能按位置传、按名字传，还能用 `*` 和 `**` 批量收发。理解这套机制是看懂 `model.generate(**inputs)` 这类调用的前提。

> 归属：**Python 标准库** —— 语言本身，不依赖第三方包。

## 1. 三种基本参数：位置 / 关键字 / 默认值

```python title="basic-args.py"
def add(x, y=10):          # x 是位置参数，y 带默认值
    return x + y

add(3)                     # 13 —— y 用默认值 10
add(3, 5)                  # 8  —— y 按位置传 5
add(x=3, y=5)              # 8  —— 按关键字传，名字写明
add(y=5, x=3)              # 8  —— 关键字参数顺序无所谓
```

- **位置参数**：按顺序传，`add(3, 5)` 里 3 给 x、5 给 y
- **关键字参数**：用 `名字=值` 传，顺序无所谓
- **默认值**：定义时 `y=10`，调用时不传就用默认值

::::note
**C++ 类比**：位置参数就是 C++ 的普通参数；关键字参数相当于 C++20 的「指名参数」；默认值两边都有。Python 的区别是关键字参数可以任意顺序传。
::::

## 2. `*args`：收集多余的位置参数

```python title="args-collect.py"
def sum_all(*args):
    print(type(args))      # <class 'tuple'>
    print(args)            # (1, 2, 3)
    return sum(args)

sum_all(1, 2, 3)           # 6 —— 三个参数被打包成元组
```

- 函数定义里 `*args` 把「多传的位置参数」**全部收进一个元组**
- 名字 `args` 是约定俗成，关键在 `*`；写成 `*xs` 也行
- 元组不可变，因为参数个数运行前不定，用 list 也没意义

## 3. `**kwargs`：收集多余的关键字参数

```python title="kwargs-collect.py"
def show(**kwargs):
    print(type(kwargs))    # <class 'dict'>
    print(kwargs)          # {'a': 1, 'b': 2}

show(a=1, b=2)             # 关键字参数被打包成字典
```

- `**kwargs` 把「多传的 `名字=值`」**全部收进一个字典**
- 字典的 key 是字符串（参数名），value 是传入的值
- 这是 `model.generate(max_new_tokens=30, do_sample=True)` 这类「一堆配置项」函数的底层写法

## 4. `**字典` 解包：展开成关键字参数调用

```python title="dict-unpack.py"
inputs = {"input_ids": tensor, "attention_mask": mask}

# 这两种写法完全等价：
model.generate(input_ids=tensor, attention_mask=mask, max_new_tokens=30)
model.generate(**inputs, max_new_tokens=30)
```

- 调用时 `**inputs` 把字典的键值对**展开成关键字参数**
- 这就是 `model.generate(**inputs)` 的根源：`inputs` 是 tokenizer 返回的字典，展开后正好喂给模型
- 可以和别的关键字参数混用：`**inputs, max_new_tokens=30`

::::tip
**定义 vs 调用的 `**`**：定义时 `def f(**kwargs)` 是「收集」；调用时 `f(**d)` 是「展开」。同一个 `**`，位置决定方向。
::::

## 5. `*列表` 解包：展开成位置参数

```python title="list-unpack.py"
args = [1, 2, 3]
add(*args)                 # 等价于 add(1, 2, 3)

print(*[1, 2, 3])          # 1 2 3 —— print 收到三个独立参数
```

- 调用时 `*列表`（或 `*元组`）把序列**展开成位置参数**
- 比 `add(args[0], args[1], args[2])` 简洁，且不依赖长度

## 小结

| 语法 | 出现位置 | 作用 |
| --- | --- | --- |
| `def f(x, y=10)` | 定义 | 位置参数 + 默认值 |
| `def f(*args)` | 定义 | 收集多余位置参数为元组 |
| `def f(**kwargs)` | 定义 | 收集多余关键字参数为字典 |
| `f(**字典)` | 调用 | 字典展开成关键字参数 |
| `f(*列表)` | 调用 | 列表展开成位置参数 |
