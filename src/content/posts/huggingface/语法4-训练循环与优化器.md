# HuggingFace 语法④：训练循环与优化器

训练循环的骨架语法——数据分批、参数过滤、反向传播三步、日志打印。全部来自 LoRA 训练代码。

## 1. 数据分批：`DataLoader`

```python title="dataloader-example.py"
dataloader = DataLoader(dataset, batch_size=4, shuffle=True)
```

- `DataLoader(数据集, batch_size=4, shuffle=True)`：自动把 Dataset 按批次打包
- `batch_size=4`：每批 4 个样本
- `shuffle=True`：每个 epoch 打乱顺序（防模型记住顺序）
- 遍历时每次拿到一个 batch 的**字典**（因为 Dataset 的 `__getitem__` 返回字典）

## 2. 遍历批次：`for step, batch in enumerate(...)`

```python title="batch-loop.py"
for epoch in range(1, 4):
    for step, batch in enumerate(dataloader):
        input_ids = batch["input_ids"].to(device)
        labels = batch["labels"].to(device)
```

- `range(1, 4)` = `[1, 2, 3]`（从 1 到 3，不含 4）——循环 3 个 epoch
- `batch["input_ids"]`：从字典按 key 取张量
- `.to(device)`：张量搬到 GPU——**每次取出来的 batch 都要搬**（数据初始在 CPU）

## 3. 过滤可训练参数：列表推导式

```python title="filter-params.py"
trainable_params = [p for p in model.parameters() if p.requires_grad]
optimizer = AdamW(trainable_params, lr=3e-4)
```

- `[p for p in model.parameters() if p.requires_grad]`：列表推导式——遍历所有参数，只留 `requires_grad=True` 的
- 这是 **LoRA 训练的关键**：原模型参数被冻结（`requires_grad=False`），只有 LoRA 的 A/B 矩阵参与优化
- `AdamW(参数列表, lr=3e-4)`：AdamW 优化器，`lr` 学习率（`3e-4` = 3×10⁻⁴ = 0.0003）

## 4. 反向传播三步

```python title="train-step.py"
loss = model(input_ids=input_ids, labels=labels).loss   # 1. 前向 + 算损失

optimizer.zero_grad()   # 2a. 清空上一次的梯度（不清会累加！）
loss.backward()         # 2b. 反向传播，算出每个参数的梯度
optimizer.step()        # 2c. 优化器按梯度更新参数

total_loss += loss.item()   # 3. 记录损失
```

三步是固定套路，顺序不能乱：

| 顺序 | 调用 | 作用 |
| --- | --- | --- |
| 1 | `zero_grad()` | 梯度清零（PyTorch 默认梯度累加） |
| 2 | `backward()` | 反向传播，填充 `param.grad` |
| 3 | `step()` | 用梯度更新参数 |

## 5. 张量转数字：`loss.item()`

```python title="item-example.py"
total_loss += loss.item()    # loss 是张量，.item() 取出 Python float
```

- `loss` 是**形状为空的标量张量**（如 `tensor(1.2345)`）
- `.item()` 转成纯 Python 数字——才能做 `+=` 累加、格式化打印

## 6. 日志打印：f-string 格式化

```python title="log-example.py"
print(f"Epoch [{epoch}/3] | Step [{step+1}/{len(dataloader)}] | Loss: {loss.item():.4f}", flush=True)
```

- `f"..."` 内用 `{表达式}` 嵌入变量
- `{loss.item():.4f}`：先算 `.item()` 再格式化为 4 位小数
- `{step+1}/{len(dataloader)}`：`len(dataloader)` 是总批数；`step` 从 0 开始所以 `+1` 显示人类序号
- `flush=True`：立即把输出刷到终端（服务器/长时间训练时防止缓冲不显示）

## 小结

| 语法 | 作用 |
| --- | --- |
| `DataLoader(dataset, batch_size=4, shuffle=True)` | 自动分批 |
| `batch["input_ids"].to(device)` | 取批次张量并搬设备 |
| `[p for p in model.parameters() if p.requires_grad]` | 过滤可训练参数 |
| `optimizer.zero_grad()` → `loss.backward()` → `optimizer.step()` | 训练三步 |
| `loss.item()` | 标量张量 → float |
| `f"{loss.item():.4f}"` + `flush=True` | 格式化日志 |
